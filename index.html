📚 Manual de vendas

📁 Importar arquivo e API do USE · só se as vendas não entrarem sozinhas
📥 Importar as vendas do USE · todas as lojas
Só a administração importa. No USE: Análise de Vendedor (Pedidos/PA) de UM dia, com todas as lojas (ou só uma) → exporte (XLS ou XML). O app separa cada vendedora na loja certa pelo código (1-, 2-, 3-…).
🔌 DS Connect · API do USE
As lojas liberadas na chave puxam o estoque a cada 10 minutos (8h às 22h) e as vendas sozinhas pela API: de hora em hora das 10h às 21h, de 10 em 10 minutos das 22h às 22h20 (horário da loja) e, depois das 22h20, a última busca fecha o dia: a gerente recebe o aviso de relatório pronto, a conferência da fila é feita e sai o status das campeãs. As outras lojas continuam pelo arquivo — quando você importar, o status é refeito com todas.
Importar o relatório do dia
No USE: Relatório de Análise de Vendedor (Pedidos/PA) → período de UM dia → XLS. Suba o arquivo aqui. Pode importar o mesmo dia mais de uma vez: o app junta os arquivos e fica com o valor mais completo de cada vendedora (não soma em dobro).
📊 Fechamento do dia para o grupo
Gera a imagem do fechamento com os números do USE e da fila para mandar no grupo do WhatsApp. Quando as vendas do dia entram no app, a gerente recebe o aviso e é só gerar e enviar.
